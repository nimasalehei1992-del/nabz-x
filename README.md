# NABZ X Prototype

## هدف
موتور هوشمند پیش‌بینی و مداخله پیشگیرانه ریسک اعتباری بانک‌ها.

## جریان
داده بانک → آماده‌سازی → مدل ML → Risk Score/PD → Early Warning → توضیح → اقدام پیشنهادی → داشبورد

## این نسخه
Prototype نمایشی با داده مصنوعی است. مدل آزمایشی Logistic Regression است.
در نسخه واقعی باید داده واقعی/ناشناس بانک، تعریف target و افق PD، اعتبارسنجی،
calibration، مقایسه مدل‌ها، SHAP، API، امنیت و Pilot انجام شود.

## اجرا
pip install -r requirements.txt
streamlit run app.py

## جمله ارائه
«این نسخه Prototype نبض ایکسه. داده‌ای که الان می‌بینید مصنوعیه، اما منطق
محصول رو شبیه‌سازی کردیم؛ سیستم داده مشتری رو دریافت می‌کنه، ریسک رو محاسبه
می‌کنه، عوامل مؤثر رو توضیح می‌ده و هشدار و اقدام پیشنهادی ارائه می‌کنه.
مرحله بعد اعتبارسنجی همین معماری با داده واقعی بانک است.»

## دفاع‌پذیری
مزیت در طول زمان از داده تاریخی، تنظیم مدل‌ها، تجربه پیاده‌سازی، یکپارچگی
با فرآیند بانک و دانش عملیاتی ساخته می‌شود؛ نه صرفاً از خود ایده.
